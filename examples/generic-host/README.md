# Generic Host Example

This directory is the checked end-to-end host generated by `agent-workflow init`.
It contains the host configuration, inherited Profile, root bootstrap, local-state
ignore rules, npm scripts and a GitHub Actions workflow.

To copy it into another repository:

1. Install a fixed `@gk0919/agent-workflow` package or `.tgz` and replace the
   local `file:../..` dependency.
2. Run `npm run workflow:init` to reconcile generated host files.
3. Put project constraints in `AGENTS.md`, bindings in
   `.agent-workflow/profile/profile.json`, and domain Skills in `.agents/skills/`.
4. Run `npm run workflow:setup`, then `npm run workflow:init:check`,
   `npm run workflow:profile`, `npm run workflow:context` and
   `npm run quality:policy`.

The Profile inherits neutral defaults. Objects merge recursively; arrays replace
their inherited values. Runtime data and local task state remain ignored.

`gitignore.template` is the packaged copy of this example's `.gitignore` because
npm excludes nested `.gitignore` files from published artifacts. The
`agent-workflow init` command still generates the real `.gitignore` in consuming
repositories.
